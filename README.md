# 위험 관리 서비스

베팅 접수의 동기 경로에서 사용자·마켓 한도와 이상 패턴을 확인합니다. 승인 여부를
즉시 반환하고, 접수된 베팅 이벤트를 소비해 Redis 집계와 패턴 이력을 갱신합니다.

## 핵심 구조

```text
betting-service ──HTTP──▶ 위험 확인 ──▶ 승인 또는 거부
       │                      │
       └─ bet.placed.v1 ──────┴─▶ Redis 기간별 집계와 이력
```

Lua 스크립트가 만료 정리, 합계 조회, 중복 방지를 한 번의 원자 연산으로 수행합니다.
빈 기간을 조회할 때 존재하지 않는 정렬 집합을 다시 확인하거나 삭제하지 않아 불필요한
Redis 명령을 줄였습니다.

## 빌드

```sh
(cd ../sportsbook-shared-protocol && ./mvnw -DskipTests install)
./mvnw clean verify
```

## 성능 조건

선택형 부하 검증은 60초 예열 뒤 초당 1,000회 요청을 60초씩 다섯 번 측정합니다.
각 회차는 p50 5ms 미만, p95 15ms 미만, p99 30ms 미만, 오류율 0.1% 미만,
검사 성공률 99.9% 초과, 누락 반복 0건을 모두 만족해야 합니다.

2026-07-13의 별도 패치 후보는 다섯 회차 모두 통과했습니다. p99는
11.217~21.326ms였고 오류와 누락 반복은 없었습니다. 이 값은 당시 소스와 패치에
묶인 비교 자료이며 현재 커밋의 릴리스 성능을 소급해 증명하지 않습니다.

재현 절차와 원본 해석은 [부하 검증 문서](load-test/README.md)에 있습니다.

## 현재 범위

API와 정책 형식에는 여러 통화가 있지만 카운터 키는 통화를 구분하지 않습니다. 따라서
현재 배포 검증 범위는 KRW이며, 혼합 통화는 키 이행 전까지 지원하지 않습니다.
